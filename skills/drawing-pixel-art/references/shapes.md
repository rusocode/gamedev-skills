# Plantillas de formas (copiar filas, no calcular a mano)

Circulos rasterizados por diametro. Todo lo curvo se arma con ellos:

- **Cupula / casco / tapa**: la mitad superior del circulo.
- **Bulbo de pocion / cabeza**: circulo entero, o circulo con las filas centrales repetidas para alargarlo
  (una elipse vertical es un circulo con mas filas del ancho maximo).
- **Anillo / rueda / ojo**: circulo de diametro D con el circulo de diametro D-6 transparente en el centro
  (pared de 3 px). Para el arco de un candado, cadena o asa: anillo al que se le borra la mitad inferior y se
  le agregan patas rectas.
- **Arco de tiro**: mitad izquierda de un circulo grande (D >= 24) de 3-4 px de pared, y una recta de 1 px que
  une las puntas.
- **Escudo**: rectangulo arriba + mitad inferior de un circulo del mismo ancho.
- **Hoja / gota / llama**: mitad superior de un circulo chico sobre un triangulo (spans que se achican de a 1-2
  columnas por fila).

Con `# espejo: x` solo hace falta la mitad izquierda de cada fila.

Regla de escalones: entre filas consecutivas el span cambia de a 1-2 columnas por lado, salvo en la fila de
arranque/cierre de una curva. Saltos de 3+ columnas producen picos y esquinas cuadradas.
