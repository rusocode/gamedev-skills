# ruso-skills

Collection of game development skills used by AI agents.

## Skills

- [**drawing-pixel-art**](drawing-pixel-art/) — Creates and fixes pixel art sprites (16–64 px) from character maps,
  validating outline, holes, symmetry, framing, and relief.

## Installation

With the [`skills`](https://github.com/vercel-labs/skills) CLI (requires Node.js):

```bash
npx skills add rusocode/ruso-skills
```

## Skill Structure

Each skill contains:

- `SKILL.md` - Instructions for the agent
- `scripts/` - Helper scripts for automation (optional)
- `references/` - Supporting documentation (optional)
